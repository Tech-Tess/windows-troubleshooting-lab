# 🖥️ Windows Event Viewer Troubleshooting

> A hands-on Windows troubleshooting lab focused on investigating system events, validating findings with PowerShell, and documenting evidence from a controlled unclean-shutdown scenario.

## 🎯 Objective

Practice using Windows Event Viewer and PowerShell to:

* Identify a relevant system event
* Investigate the event source and Event ID
* Review detailed event data
* Cross-check Event Viewer findings with PowerShell
* Distinguish an observed event from its underlying cause
* Document troubleshooting evidence accurately

## 🖥️ Environment

* Windows 11 25H2
* VMware virtual machine
* Windows Event Viewer
* PowerShell

## 🧩 Scenario

A controlled unclean-shutdown condition was created in the Windows 11 virtual machine.

The VMware VM was intentionally powered off without performing a normal Windows shutdown. After the VM was started again, Windows Event Viewer was reviewed to determine what system event was generated by the unclean shutdown.

This provided a controlled environment for investigating how Windows records an unexpected shutdown.

## 🔎 Investigation & Procedure

### 01 · Create the Test Condition

The Windows 11 VM was intentionally powered off through VMware without first shutting down Windows normally.

The VM was then started again.

This was a controlled test condition and was **not treated as evidence of an actual hardware or Windows failure**.

### 02 · Open Event Viewer

Opened Windows Event Viewer using:

```text
eventvwr.msc
```

Navigated to:

**Windows Logs → System**

### 03 · Identify the Relevant Event

A Critical event was identified in the System log.

| ------------- | ------------------------------ |
| Log           | System                         |
| Level         | Critical                       |
| Source        | Microsoft-Windows-Kernel-Power |
| Event ID      | 41                             |
| Task Category | 63                             |
| Computer      | Windows11VM                    |
